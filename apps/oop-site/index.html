01 · What it is소개

Agents are good.
Juggling them is not. 에이전트는 훌륭합니다.
여러 개를 오가는 일이 문제죠.

Each coding agent lives in its own terminal or app, with its own login, history and approval prompts. OOP puts them side by side with one diff, one terminal and one approval flow. 코딩 에이전트마다 터미널이나 앱, 로그인, 기록, 승인 프롬프트가 따로 있습니다. OOP는 이들을 나란히 놓고 diff, 터미널, 승인 흐름을 하나로 맞춥니다.

Not a hosted service. OOP runs on your computer. Projects, provider logins and agent work stay there. There is no OOP account and no OOP server. 호스팅 서비스가 아닙니다. OOP는 내 컴퓨터에서 실행됩니다. 프로젝트, provider 로그인, 에이전트 작업이 모두 그곳에 남고, OOP 계정도 OOP 서버도 없습니다.

Built on T3 Code. OOP is a fork of T3 Code by T3 Tools Inc. (MIT), based on upstream v0.0.44. Almost all of the foundation is their work. T3 Code 기반입니다. OOP는 T3 Tools Inc.의 T3 Code(MIT)를 포크한 프로젝트이며 업스트림 v0.0.44를 기반으로 합니다. 기반 코드의 거의 전부가 T3 Code 팀의 작업물입니다.

03 · OOP Crew

Cheap models for the bulk.
A strong one to check. 대부분은 저렴한 모델로.
검토는 강한 모델로.

Turn on Crew next to the model picker. The chat's own model becomes the brain, and OOP routes the rest by role. 모델 선택기 옆에서 Crew를 켜면, 채팅의 모델이 brain이 되고 나머지는 역할에 따라 나뉩니다.

Brain Plans and talks to you. 계획을 세우고 사용자와 대화합니다.
Worker Routine work: searches, edits, tests. 반복 작업: 검색, 수정, 테스트.
Expert Hard implementation. 어려운 구현.
Auditor Reviews turns that changed files. 파일을 바꾼 턴을 검토합니다.
  • Presets: OOP pick, Speed, Quality, Budget, with a per-role model override. 프리셋: OOP pick, Speed, Quality, Budget. 역할별로 모델을 직접 지정할 수도 있습니다.
  • If a crew model fails, for example it ran out of credit, OOP hands the task to another signed-in model of the same level. crew 모델이 크레딧 소진 등으로 실패하면, 같은 수준의 다른 로그인된 모델에 작업을 넘깁니다.
  • Small, test-passing changes of 20 lines or fewer are not audited. 테스트를 통과한 20줄 이하의 작은 변경은 감사하지 않습니다.
  • Crew runs several models per chat, so it multiplies usage. Check the Usage page. Crew는 채팅 하나에서 여러 모델을 돌리므로 사용량이 늘어납니다. 사용량 페이지를 확인하세요.

05 · Install설치

One command.
Checked before it installs. 명령 한 줄.
설치 전에 검증합니다.

The installer downloads the desktop app from a GitHub release and verifies its SHA-256 before installing. It needs no Node.js, pnpm, git or compiler. 설치 스크립트는 GitHub 릴리스에서 데스크톱 앱을 내려받아 설치 전에 SHA-256을 검증합니다. Node.js, pnpm, git, 컴파일러가 필요 없습니다.

macOS · Apple Silicon tested검증됨 

curl -fsSL https://raw.githubusercontent.com/AIBeginnerX/oh-our-pi-desktop/main/scripts/install-desktop.sh | sh

Installs ~/Applications/OOP.app (an existing /Applications/OOP.app is updated in place). Remove the app to uninstall. The app is not notarized: if macOS warns, right-click it and choose Open, or use System Settings → Privacy & Security → Open Anyway. ~/Applications/OOP.app에 설치합니다(기존 /Applications/OOP.app이 있으면 그 앱을 갱신). 삭제하려면 앱을 지우면 됩니다. 앱은 공증(notarize)되지 않았으므로 macOS가 경고하면 앱을 우클릭해 열기를 고르거나, 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기를 쓰세요.

Windows · x64 experimental실험적 

irm https://raw.githubusercontent.com/AIBeginnerX/oh-our-pi-desktop/main/scripts/install-desktop.ps1 | iex

Run in PowerShell. Silent per-user install with a Start menu entry; uninstall from Settings → Apps. Windows SmartScreen may warn: click More info → Run anyway. The Windows installer was built by the maintainer and is not yet verified on clean machines. PowerShell에서 실행하세요. 사용자 단위 무음 설치이며 시작 메뉴에 등록됩니다. 삭제는 설정 → 앱에서 합니다. SmartScreen이 경고하면 추가 정보 → 실행을 누르세요. Windows 설치 파일은 개발자가 빌드했으며 깨끗한 환경에서는 아직 검증되지 않았습니다.

Linux · x64 not verified미검증 

curl -fsSL https://raw.githubusercontent.com/AIBeginnerX/oh-our-pi-desktop/main/scripts/install-desktop.sh | sh

Installs an AppImage under ~/.local/share/oop-desktop, a launcher at ~/.local/bin/oop-desktop and a menu entry. It needs GTK and NSS runtime libraries. The Linux GUI has not been verified. AppImage를 ~/.local/share/oop-desktop에, 실행 파일을 ~/.local/bin/oop-desktop에, 메뉴 항목을 함께 설치합니다. GTK와 NSS 런타임 라이브러리가 필요하며, Linux GUI는 아직 검증되지 않았습니다.

Build it yourself (macOS Apple Silicon)직접 빌드 (macOS Apple Silicon) Node 24.x · pnpm 11.10.0 · gitNode 24.x · pnpm 11.10.0 · git 

git clone https://github.com/AIBeginnerX/oh-our-pi-desktop.git
cd oh-our-pi-desktop
node scripts/macos.mjs doctor
node scripts/macos.mjs setup
node scripts/macos.mjs package

Run the script with node, not through pnpm. package writes an ad hoc signed DMG to release/macos/. Windows and generic dev paths are in the README. 스크립트는 pnpm이 아니라 node로 직접 실행하세요. package는 ad hoc 서명된 DMG를 release/macos/에 만듭니다. Windows와 일반 개발 경로는 README를 참고하세요.

To update later, quit OOP and rerun the same command; your data is kept. See Releases and the install guide. 나중에 업데이트하려면 OOP를 종료하고 같은 명령을 다시 실행하면 되며 데이터는 유지됩니다. Releases와 설치 안내를 참고하세요.

After installing설치한 뒤에

  1. Install and sign in to one provider CLI (the desktop installer does not do this for you). Settings → Providers shows the state. provider CLI 하나를 설치하고 로그인하세요(데스크톱 설치 스크립트가 대신해 주지 않습니다). 상태는 설정 → Providers에서 볼 수 있습니다.

  4. Review the result in the diff panel. diff 패널에서 결과를 검토합니다.

Who is OOP for?누구를 위한 앱인가요?

Developers who already pay for one or more coding-agent subscriptions or API plans, can accept an early, unsigned desktop app, and want one control surface. If you want a polished, signed, auto-updating product, the upstream T3 Code is the better fit today. 이미 코딩 에이전트 구독이나 API 요금제를 쓰고 있고, 초기 단계의 서명되지 않은 데스크톱 앱을 감수할 수 있으며, 하나의 제어 화면을 원하는 개발자를 위한 앱입니다. 서명되고 자동 업데이트되는 완성형 제품을 원하신다면 현재로서는 업스트림 T3 Code가 더 잘 맞습니다.

What does it cost?비용은 얼마인가요?

OOP itself is free and MIT licensed. Every provider uses your own subscription or API credit, and Crew multiplies usage by running several models per chat. The Usage page shows estimates, not your bill. OOP 자체는 무료이며 MIT 라이선스입니다. 모든 provider는 내 구독이나 API 크레딧을 쓰고, Crew는 채팅 하나에서 여러 모델을 돌리므로 사용량이 늘어납니다. 사용량 페이지는 청구액이 아닌 추정치를 보여 줍니다.

Is it safe to let agents run?에이전트를 실행해도 안전한가요?

Agents run with your account's permissions and can edit files and run commands. New threads default to Full access. For untrusted repositories, switch to Supervised (Settings → General → New threads). Treat pairing links as passwords and prefer Tailscale away from home. 에이전트는 내 계정의 권한으로 실행되어 파일을 수정하고 명령을 실행할 수 있습니다. 새 스레드의 기본값은 Full access이므로, 믿을 수 없는 저장소에서는 Supervised로 바꾸세요(설정 → General → New threads). 페어링 링크는 비밀번호처럼 다루고, 집 밖에서는 Tailscale을 권장합니다.

Does OOP collect telemetry?텔레메트리를 수집하나요?

OOP has no servers and the maintainers receive nothing from your app. The anonymous usage reporter inherited from upstream is off by default and needs your own project key to turn on. OOP에는 서버가 없고 개발자는 앱에서 아무것도 받지 않습니다. 업스트림에서 물려받은 익명 사용 통계 보고기는 기본으로 꺼져 있고, 켜려면 직접 발급한 프로젝트 키가 필요합니다.
