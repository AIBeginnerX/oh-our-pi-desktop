# Reports in chat

When an agent reports results, analysis, or a plan, T3 Code draws its answer as a report: charts,
key-figure cards, progress bars, and flow diagrams animate into the conversation, so the answer
reads at a glance without a separate document. Agents add these on their own when a reply carries
numbers or a process; ask for a chart or a diagram to get one on demand.

Each figure has a **Source** button that shows the data or diagram text behind it. Turn on your
system's reduced-motion setting to show figures without animation.
