# Notifications

OOP tells you when a thread needs you: it finishes, fails, or waits for your
input or approval. Choose the channels in **Settings → General → Thread
notifications** — an in-app toast, a system notification while the window is
not in view, and a sound, separately or together.

## No-activity alerts

A running agent that shows no activity for a while can alert you, so a quiet
turn does not slip by. Under **Settings → General → Alert when a running agent
shows no activity for**, pick 10, 20, or 30 minutes; it is off by default. The
alert is only a notification — it never stops, pauses, or retries the agent —
and it arrives within about half a minute of crossing the threshold. Any new
activity re-arms it, so each silence alerts once, and a thread waiting for your
approval or input never alerts.
